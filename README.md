## ⚙️ Core AI Concepts

### 🧩 State Representation

Each problem is modeled as a structured state:

* Board configurations
* Entity distributions
* Game positions

---

### 🌐 State Space

The system explores a **graph of all possible states**:

* Nodes → states
* Edges → valid transitions

---

### 🔄 State Transition

The system applies actions to move between states:

* Valid moves only
* Controlled transitions
* Goal-driven progression

---

### ⚠️ Constraint Satisfaction

Rules define what is allowed:

* Prevent invalid states
* Reduce search complexity
* Ensure logical correctness

---

### 🔍 Search Process

The system performs **implicit search** by:

* Exploring possibilities
* Evaluating states
* Progressing toward a goal

---

## 🧩 Implemented Problems

---

### 🛶 Missionaries & Cannibals

A constraint-heavy logical problem involving safe transportation under strict rules.

**AI Focus:**

* Constraint satisfaction
* Safe state validation
* Sequential reasoning

---

### 👑 8-Queens Problem

A classical combinatorial problem where queens must be placed without conflict.

**AI Focus:**

* Constraint satisfaction (CSP)
* Conflict detection
* Search space reduction

---

### 🧩 8-Puzzle Problem

A sliding puzzle requiring transformation from an initial to a goal configuration.

**AI Focus:**

* State-space search
* Pathfinding
* Sequential decision-making

---

### ❌⭕ Tic Tac Toe

A strategic game environment representing decision-making systems.

**AI Focus:**

* Game state evaluation
* Turn-based reasoning
* Strategy modeling

---

## 🧠 System Design (AI Workflow)

The system follows a structured intelligent agent model:

1. Define Problem
2. Represent State
3. Identify Actions
4. Apply Constraints
5. Transition States
6. Validate States
7. Evaluate Goal

This reflects real-world AI system design patterns.
